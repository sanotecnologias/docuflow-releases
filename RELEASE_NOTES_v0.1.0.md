# DocuFlow v0.1.0

Primera version distribuible de DocuFlow.

## Plataformas

- macOS Apple Silicon: `DocuFlow-0.1.0-mac-arm64.dmg`
- Windows x64: `DocuFlow-0.1.0-win-x64.exe`

## Incluye

- Generacion de documentacion tecnica para microservicios Spring Boot Java/Kotlin.
- Exportacion de documentos Word y PDF.
- Analisis de endpoints, controladores, dependencias relevantes, servicios externos, base de datos y configuracion.
- Diagramas Mermaid y diagramas graficos generados para documentacion.
- Integracion con licenciamiento de SanoTecno.

## Nota de instalacion

En macOS, al no estar firmada la aplicacion, puede ser necesario abrirla desde Finder con clic derecho y seleccionar `Abrir` la primera vez.
